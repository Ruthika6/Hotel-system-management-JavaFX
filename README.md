# Hotel-system-management-JavaFX
A simple JavaFX-based Hotel Management System developed using Object-Oriented Software Development (OOSD) concepts.
The application helps manage hotel rooms, bookings, and checkouts through a user-friendly GUI.

✨ Features
Add and manage hotel rooms
Book available rooms for guests
Checkout guests and update room availability
Modern JavaFX UI with CSS styling
